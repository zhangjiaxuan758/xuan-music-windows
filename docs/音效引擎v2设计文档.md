# 小轩音乐 · 音效引擎 v2 与音质策略设计文档

> 版本：1.6.5 (10625+) · 本文档描述本轮（2026-11-08）音效 / 音质 / 远程配置的完整设计。
> **重要声明**：所有音效参数均为小轩音乐的**公开等效实现**，仅预设名称与网易云「鲸云音效」同名；
> 网易云从未公开其内部 DSP 参数，本文档不声称任何参数为官方参数。

## 1. 共享 JSON 预设结构（跨端一致）

文件位置：
- Web 端内嵌：`client/src/services/audioEffects.ts` → `XUAN_EFFECT_PRESET_DATA`（可用 `exportXuanEffectPresetsJson()` 导出）
- Android 参考实现：`packaging/exoplayer-dsp/xuan-effect-presets.json`（与 Web 逐字段一致）

```jsonc
{
  "version": 2,
  "presets": {
    "<presetId>": {
      "headroomDb": -4,                    // 前置增益（负值=留余量）
      "eq": [                              // 多段参数 EQ
        { "type": "lowshelf|peaking|highshelf", "freq": 110, "gain": 8.5, "q": 0.7 }
      ],
      "glue": {                            // 胶水压缩（null=旁通）
        "threshold": -16, "ratio": 4, "attack": 0.008, "release": 0.12, "knee": 10
      },
      "saturation": { "drive": 0.42, "mix": 0.34 },  // 并联饱和（tanh，干湿混合）
      "stereoWidth": 1.05,                 // M/S 立体声展宽（1=原样）
      "space": {                           // 空间处理
        "mode": "none|hrtf3d|reverb",
        "wet": 0.55,                       // 湿声比例
        "irSeconds": 0.8,                  // 混响 IR 时长（0.5~3s）
        "spinHz": 0.08, "radius": 1.6      // 3D 旋转速度/半径
      },
      "limiterCeilingDb": -1               // 真峰值限制器目标
    }
  }
}
```

7 种预设：`superBass 超重低音` / `surround3d 3D环绕` / `panoramic 全景环绕` /
`hdVocal 高解析人声` / `clearVocal 清澈人声` / `hifiLive HiFi现场` / `immersive 震撼全景`。
管理端可下发 `effects.enabled`（总开关）与 `effects.presets`（白名单），全端实时生效。

## 2. Web 端节点链（Web Audio API）

```
音源 → input(Gain)
     → pre(Gain, headroomDb)
     → EQ[0..3] (BiquadFilterNode: lowshelf/peaking/highshelf)
     → glueCompressor (DynamicsCompressorNode, thr=-16dB ratio=4 A=8ms R=120ms)
     ├─ dry Gain(1-mix·0.5) ──────────────┐
     └─ WaveShaper(tanh 饱和, 2x oversample) → wet Gain(mix) ─┤
                                                             ▼
     M/S 展宽: Splitter → mid=(L+R)/2 / side=(L-R)/2 × width → Merger
     ├─ spaceDry ──────────────────────────────────────────┐
     ├─ PannerNode×2 (HRTF, L/R 绕头 0.08Hz LFO 旋转) → hrtfWet ┤
     └─ ConvolverNode (程序化指数衰减立体声 IR) → reverbWet ────┤
                                                              ▼
     限制器: WaveShaper(brickwall, 4x oversample, ceiling=-1dBFS) → ceiling(0.98) → 输出
```

要点：
- 常驻节点一次构建；切预设只动 AudioParam（`setTargetAtTime` 60ms 平滑），不重建图、不爆音。
- HRTF 不可用时自动旁通（`try/catch`），由展宽+混响兜底。
- IR 由程序生成（指数衰减噪声 + 5ms 起坡），无资源下载，移动端 0.5~3s。

## 3. Android 端（ExoPlayer AudioProcessor，不依赖 WebView/系统 AudioEffect）

骨架：`packaging/exoplayer-dsp/XuanAudioProcessor.kt`（Kotlin，media3 `AudioProcessor`）。

- `Preamp → 8-band biquad EQ(RBJ cookbook) → 胶水压缩(RMS 近似) → 并联饱和(tanh) →
  M/S 展宽 → 简化 comb 混响 → 软限幅(-1 dBFS)`
- 预设从同一份 `xuan-effect-presets.json` 读取；`setPreset()` 参数一阶平滑过渡。
- 3D 环绕高配设备可换 ExoPlayer GVR extension 的 `GvrAudioProcessor`（双耳 HRTF）。
- **系统 AudioEffect 只作降级兜底**：CPU 弱设备上把空间类预设映射为系统
  `Virtualizer + PresetReverb`、超重低音映射 `BassBoost`；Virtualizer 在 API 35
  已 deprecated，不作为主路径。

## 5. 防削波 / 参数平滑 / 一致性 / 测试

**防削波**
1. 前置 headroom 按预设预留 2~5dB；
2. 并联饱和 `tanh(x·k)/k`：小信号严格单位增益，只压峰；
3. EQ 增益再过 `tanh` 软限（cap 9dB）；
4. 末端 brickwall 限幅器（4x oversample WaveShaper）把真峰值压进 -1 dBFS；
5. 全链 32-bit float（Web Audio 内部即 float32；Android 端 double 运算）。

**参数平滑**：所有 AudioParam 用 `setTargetAtTime(τ≈60ms)`；Android 端每样本一阶趋近；IR 时长变化才重建 buffer。

**跨端一致性**：同一 JSON → Web 映射到节点参数，Android 由 RBJ 公式算 biquad 系数；预设 id/参数逐字段一致。

**测试建议**
- 单元：0dBFS 正弦输入 → 输出峰值 ≤ 0.891（-1 dBFS）；静音输入输出为 0；切预设 200ms 内无样本溢出。
- 听感清单：超重低音开满不破音/不轰头；人声预设齿音不过亮；3D 环绕旋转无明显摆幅爆音；混响尾巴无金属感。
- 性能：中端 Android 手机 Convolver 2s IR + 2×HRTF panner 帧率与功耗；必要时 wet 预设降 IR 至 0.8s。

## 6. 音质策略（未登录 / 非会员 / 会员）

官方档位全集：`standard 128k / higher 192k / exhigh 320k / lossless / hires / sky 沉浸环绕声 / jymaster 超清母带`。

- **未登录**：自动用官方匿名可播的最高档（standard 起步），从 `FULL_QUALITY_CHAIN` 依次降级重试，以官方返回 `level/br` 显示真实档位；用户可往下手动切换。
- **登录非会员**：从所选档起依次降级；会员档自动回落 `exhigh` 并在切换时轻提示（`account.qualityNeedVip`）。
- **会员**：默认请求最高会员档，可切换官方全部 7 档。
- 实际档位一律以官方 `/song/enhance/player/url/v1` 返回的 `level`（缺省用 `br`）为准显示。

## 7. 管理端统一控制 + API 热切换

- 管理端一套配置同时控制**网页端 + 客户端**（同一 `/api/config` 下发），保存即经 SSE（网页）与 4s 轮询（App）实时生效，不刷新不重启。
- 可控项：应用信息/板块/推荐/榜单/音质策略（默认档、非会员回落档、自动最高、会员全档开关）/音效总开关与预设白名单/UI 行为/更新下发等。
- **更换网易云官方 API**：管理端改 `netease.host`（严格 URL 校验），eapi 密钥仍只在服务端保管不可覆写；`eapi_proxy` 每请求动态读取 host → **立即生效**。
- **登录态**：Cookie 保存在用户设备并继续随请求携带，换 host 通常不掉登录；若新接口判定登录失效，客户端按现有受限流程提示重新登录。
